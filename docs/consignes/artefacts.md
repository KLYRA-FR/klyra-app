# Artefacts, rendus et documents

- **Rendus des agents = l’écran Artefacts** (`src/lib/rendus.ts`, `electron/rendus.ts`). Trois places : le code et les sources d’un projet dans son dossier (son dépôt) ; les livrables à montrer, **copiés par l’app** dans `~/.klyra/rendus/<agent>/` ; le brouillon dans `atelier/<agent>/`. Un agent publie par l’outil MCP `publier_artefact` (chemin complet d’un fichier, ou d’un dossier de page avec `index.html`, 300 Mo au plus, sans `node_modules` ni `.git`), demandé par `CONSIGNE_ARTEFACTS` pour **tout fichier demandé, quel que soit son format** (par la personne ou par l’agent qui a confié le travail, donc aussi dans un fil) et tout rendu à montrer, avant de dire « livré ». `state.rendus` garde la copie (`chemin`), l’original (`origine`), l’agent, la conversation, le projet ; republier le même original remplace sa copie ; retirer supprime la copie (`supprimerCopieRendu` refuse tout chemin hors de l’espace des rendus), jamais l’original. « Enregistrer dans… » copie le livrable dans un dossier choisi (celui du projet proposé) : c’est la personne qui décide de le mettre dans un dépôt. Vignette : l’image, ou la page dessinée hors écran (fenêtre isolée, sans navigation) ; ouverture par l’app du système seulement pour les types connus (`OUVRABLES`), sinon le dossier. Le panneau Fichiers d’une conversation montre ses livrables, et dans la conversation directe ceux de l’agent avec ses deux dossiers. Les artefacts claude.ai sont une source **facultative** (`state.artefactsClaude`), relue à l’ouverture de l’écran dans la galerie `claude.ai/code/artifacts`, ouverte hors écran avec la session claude.ai de l’app (`listerArtefacts` : liens de la page et réponses JSON, cf. `electron/artefacts-liste.ts`). NEVER par Claude Code : l’outil Artifact n’existe pas dans le Claude Code installé sur un poste ; les textes de l’écran ne parlent pas de Claude. Sur un VPS : le serveur MCP local (`serveur/ia.mjs`) propose `publier_artefact` à chaque session, l'agent et la conversation en en-têtes (`X-Klyra-Agent`, `X-Klyra-Conversation`) ; `serveur/rendus.mjs` vérifie (sous le dossier de klyra, 300 Mo, page par son index.html), retient la publication (`donnees/rendus.json`) et l'annonce par le journal (événement `rendu`) ; l'app l'ajoute à Mes artefacts de ce serveur sans la copier dans `~/.klyra/rendus` (origine `<serveur>#<chemin>` ; `htmlRenduVps` et `ouvrirRenduVps` lisent le serveur). Pas encore : version téléphone.
- **Atelier : un dossier par agent hors projet** (`electron/atelier.ts`, compilé en `serveur/atelier.mjs` pour le VPS) : `~/.klyra/atelier/<agent>/` (l’assistant : `principal/`). Une session Claude Code commencée dans l’ancien atelier commun y reste (Claude Code retrouve une session par son dossier) ; Codex garde l’atelier commun.
- **Artefacts de l’équipe** (`convex/artefactsEquipe.ts`, `src/lib/artefacts-equipe.tsx`, onglet « Équipe » de l’écran Artefacts) : liens claude.ai partagés volontairement, membres actifs seulement, qui l’a partagé seul pour modifier ou retirer, un lien actif une fois (`lienArtefact`, `convex/model/artefacts.ts`). Seul le lien part : jamais d’aperçu ni de contenu de la page. Même construction que la bibliothèque (`pour`, rien sur le disque). « Mes artefacts » reste local (`conversations.json`) ; NEVER d’artefact mis d’office dans la liste d’un poste.
- **Documents KLYRA** (`convex/documentsKlyra.ts`, `src/lib/documents-klyra.tsx`) : Convex ne garde que les HTML partagés à l'équipe. Un privé reste dans son espace (copie locale ou fichier du VPS), il n'est pas dans cette table. La ligne naît au partage, pas à `publier_artefact`. `lieu` null = Ce PC, sinon l'adresse du VPS : `lister` et `lire` ne renvoient que cet espace. L'auteur seul `reprendre` ou `supprimer` (le fichier quitte Convex). Republier la même origine dans le même espace remplace la carte du même auteur. Un autre membre crée la sienne : il n'écrase pas le fichier, et l'auteur garde le retrait. Aucun plafond. `espace` additionne les octets encore dans Convex, tous espaces, sans contenu (`complet` faux au-delà de 2 000) : c'est le coût, pas la liste. L'écran Artefacts suit l'espace actif. « Partager à l’équipe » sur une page HTML dépose le fichier puis crée la ligne ; « Ne plus partager », ou retirer la carte, l'enlève. L'onglet Équipe montre ces pages sans ouvrir l'adresse de stockage, et les liens claude.ai seulement sur Ce PC. `origine` n'est renvoyée qu'à l'auteur. Pas encore : la fenêtre isolée. Test : `pnpm test:convex`, `src/lib/rendus-espace.test.ts`.
